# Data

This folder contains the curated source-data files and analytical datasets used in the study “From pipeline growth to first-of-a-kind deployment: market readiness across the global small modular reactor landscape”.

## Data overview

- `fig01_pipeline_and_phase_panels_source_data.xlsx` — source data for Figure 1.
- `fig02_design_pipeline_source_data.xlsx` — source data for Figure 2.
- `fig03_start_year_source_data.xlsx` — source data for Figure 3.
- `fig04_predictors_source_data.xlsx` — source data for Figure 4 and associated predictor analysis.
- `fig05_technology_source_data.xlsx` — source data for Figure 6.
- `figS1_regions_source_data.xlsx` — source data for Supplementary Figure 1.
- `graphical_abstract_source_data.xlsx` — source data for the graphical abstract regional-readiness panel.
- `iaea_trl_crosscheck_source_data.xlsx` — IAEA-derived source dataset used for the Supplementary Table 6 TRL cross-check.
- `smr_market_readiness_master_dataset.xlsx` — clean analytical dataset used for the main market-readiness analysis.
- `smr_market_readiness_master_dataset_2026.xlsx` — broader harmonised NEA Dashboard archive covering Editions 1–3, including source links, dashboard assessments, Edition 3 full sample, Edition 3 SMR-only sample and fuel-form coding.

Figure-specific source-data files are provided separately from the broader master datasets to make each figure easier to reproduce. Working files, exploratory spreadsheets and undocumented intermediate files are not included.
