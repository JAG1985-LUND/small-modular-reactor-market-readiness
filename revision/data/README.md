# Source data

This directory contains the source-data workbooks supporting Figures 1–10 of the revised manuscript and the associated supplementary analyses.

The directory includes:

- **Main figures:** Source-data workbooks for Figures 1–10.
- **Supplementary Tables.xlsx:** Consolidated Excel workbook containing Supplementary Tables S1–S18, corresponding to the tables reported in the supplementary materials.
- **Supplementary Table S14 regression outputs:** Additional workbook containing model estimates, diagnostics and supporting worksheets for the joint regional and technological readiness analysis, including the full SMR sample and conventional SMRs excluding microreactors. China and Russia are combined into a single regional category. This workbook is retained for transparency and provenance.
- **Additional supplementary source data:** Workbooks supporting supplementary analyses, robustness checks and validation exercises.

Supplementary analyses without dedicated R scripts are generated through the relevant main-figure scripts or associated analysis scripts in `revision/scripts/`.
