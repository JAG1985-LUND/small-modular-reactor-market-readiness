# Outputs

This folder contains reproducible outputs generated from the analysis scripts, including exported figures, graphical abstract files and model-result summaries.

## Output overview

- `fig01_a-i.pdf` / `fig01_a-i.png` — Figure 1 export.
- `fig02_a-c.pdf` / `fig02_a-c.png` — Figure 2 export.
- `fig03_a-f.pdf` / `fig03_a-f.png` — Figure 3 export.
- `fig03_predictors_model_results.csv` — model-output table associated with Figure 3.
- `fig04_a-d.pdf` / `fig04_a-d.png` — Figure 4 export.
- `fig05_a-f.pdf` / `fig05_a-f.png` — Figure 5 export.
- `fig05_regions_panel_values.csv` — regional panel values associated with Figure 5.
- `graphical_abstract_pdf.pdf` / `graphical_abstract_png.png` — graphical abstract regional-readiness panel exports.
- `supplementary_table_6_iaea_trl_crosscheck.xlsx` — consolidated workbook of IAEA–TRL cross-check outputs for Supplementary Table 6.

Final publication files may differ slightly from these outputs if figures or tables are reformatted for journal submission.
